# ShoppyGlobe Backend API

## Project Overview

ShoppyGlobe Backend is an e-commerce REST API developed using Node.js, Express.js, and MongoDB.

The backend provides APIs for managing users, products, and shopping cart items. JWT-based authentication is implemented to protect cart routes and allow only authenticated users to access their cart.

### Main Features

- User registration and login
- JWT-based authentication
- Product management
- Shopping cart management
- MongoDB database integration
- Input validation
- Error handling
- Protected cart routes
- API testing
- MongoDB collection documentation
